fix(bird): harden query executor sandbox and improve csv reporter robustness

- Query Executor (`src/bird/query_executor.py`):
  - Strip single/double quoted string literals and comments prior to regex inspection in `_verify_read_only_intent`, preventing false-positive permission blocks on read-only queries with mutation keywords (e.g., `WHERE status = 'DELETE'`).
  - Introduce safe wrappers (`_safe_trig`, `_safe_abs`, `_safe_sign`) for SQLite mathematical and trigonometric UDFs (`SIN`, `COS`, `TAN`, `ASIN`, `ACOS`, `ATAN`, `RADIANS`, `DEGREES`, `ABS`, `SIGN`), gracefully evaluating non-numeric/text input to SQL `NULL` instead of aborting queries with `OperationalError`.

- CSV Reporter (`src/bird/csv_reporter.py`):
  - Add defensive sort by `attempt_number` in `export_predictions_from_rows` and `generate_summary` to ensure accurate final predictions and self-correction calculations regardless of row ordering.
  - Support unified key resolution (`sql`/`agent_sql` and `erro`/`error`) in `format_markdown_report`, ensuring attempts extracted from either in-memory states or serialized CSV rows render properly.
  - Guard `format_result_rows_markdown_table` against 0-column tuples (`[()]`), rendering `"*(0 columns returned)*"`.

- Tests (`tests/test_bird_eval.py`):
  - Add test cases covering string literal mutation bypass, safe non-numeric trig evaluation, 0-column table formatting, and markdown report key fallback.
